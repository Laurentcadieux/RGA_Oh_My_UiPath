## Mapping hints for UiPath adaptation

- Skill catalog → frontmatter-driven registry with alias/entitlement policy (§1)
- Autopilot stages → `PipelineStageAdapter`-style interface + immutable profile descriptor + evidence-gated Stop hook (§2)
- Team runtime → file-based mailboxes/heartbeats translate to UiPath queues/jobs; native-vs-external worker split preserved (§3)
- Provider routing → one contract per external CLI, quirks isolated in a launcher, availability detection renders skill guidance (§4)
- Ralph → PRD story loop with mechanical verify exit codes + baseline fingerprints + amendment ledger (§5)
- Deep interview → weighted ambiguity gate + topology lock + challenge-mode state machine (§6)
- Lookout → advisory-only mechanical preflight with evidence-based findings (§7)
- Config → layered JSONC merge with atomic closed-schema profiles (§9)
